# Sorry website 💔 → 💖

1. Put photos in `images/` as `1.jpg` … `5.jpg` (or edit the list in `script.js`).
2. Edit the names, letter, promises and thank-you message in the `CONFIG` block at the top of `script.js`.
3. Optional: add a soft song as `music.mp3`.
4. Push to GitHub → Settings → Pages → deploy from `main` / root.
