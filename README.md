# Sorry website 💔 → 💖

Everything lives in one file: `index.html` (styles and code are inside it).

1. Put photos in `images/` as `1.jpg` … `5.jpg` (or edit the list in the `CONFIG` block near the bottom of `index.html`).
2. In that same `CONFIG` block, edit the names, letter, promises and thank-you message.
3. Optional: add a soft song as `music.mp3` next to `index.html`.
4. Push to GitHub → Settings → Pages → deploy from `main` / root.
